## 1. 产品概述

个人睡眠记录与梦境日记分析系统（DreamLog）是一款纯前端Web应用，旨在帮助用户科学记录每日睡眠数据与梦境内容，通过可视化分析发现睡眠与梦境之间的关联规律，并提供助眠工具辅助入睡。数据完全存储于浏览器IndexedDB，配合Docker+Nginx实现一键部署。

- 目标用户：关注睡眠健康的都市人群、梦境探索爱好者
- 核心价值：将睡眠数据记录与梦境日记融合，通过关联分析揭示"咖啡因→噩梦""晚睡→清晰梦"等隐含趋势，提供可操作的睡眠改善建议

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 无需注册，数据本地存储 | 全部功能 |

### 2.2 功能模块
1. **睡眠记录页**：录入入睡/起床时间、入睡耗时、质量评分、影响因素标签
2. **梦境日记页**：记录梦境文本、标记梦境类型、添加情绪标签、词云统计
3. **关联分析页**：睡眠与梦境的关联趋势散点图与堆积柱状图
4. **趋势看板页**：周/月睡眠时长曲线、入睡时间热力图、效率趋势
5. **助眠工具页**：4-7-8呼吸引导、白噪音混音器、拉伸动作卡片
6. **梦境回溯页**：时间线串联多天梦境、情绪标签筛选阅读
7. **月度报告页**：PDF导出月度睡眠报告含图表与建议

## 3. 核心流程

### 3.1 睡眠记录流程
用户进入睡眠记录页 → 输入入睡/起床时间 → 系统自动计算时长与效率 → 评分并选择影响因素 → 保存至IndexedDB → 跳转至梦境日记页

### 3.2 梦境记录流程
用户进入梦境日记页 → 输入梦境文本 → 选择梦境类型与情绪标签 → 保存 → 词云实时更新

### 3.3 分析与导出流程
用户进入关联分析页/趋势看板页 → 选择时间范围 → 查看图表 → 切换至月度报告 → 导出PDF

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深紫渐变（#0F0A1A → #1A0E2E → #2D1B4E），模拟夜空深邃感
- **辅助色**：星光金（#FFD700）、月光银（#C0C0C0）、极光蓝绿（#00CED1）
- **按钮风格**：圆角胶囊按钮，半透明毛玻璃效果（backdrop-blur），悬停时星光金边框
- **字体**：标题使用 Noto Serif SC 衬线体营造静谧氛围，正文使用 Noto Sans SC 无衬线体保证可读性
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式内容展示，全局星空粒子背景
- **图标风格**：线性图标（lucide-react），星光金色调

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度1024px
- 平板适配：导航栏折叠为底部Tab
- 移动端适配：单列布局，卡片全宽

### 4.4 动效设计
- 页面切换：淡入淡出 + 微滑动
- 卡片悬停：轻微上浮 + 阴影增强
- 数据保存：星光闪烁确认动效
- 星空背景：缓慢飘移的粒子，鼠标跟随产生涟漪
